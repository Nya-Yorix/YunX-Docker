账号备份

导出全部已配置平台凭证（含视频平台）为口令加密的 .yunx 文件，可在桌面版或另一台服务器导入。口令不会存储 —— 丢失后备份无法解密。

从 .yunx（加密）或 .json（明文）备份恢复；备份内的同名平台凭证会覆盖当前值，其余平台不受影响。
